# Programming Lab - Python Course

Welcome to the **programminglab** repository. This repository contains the laboratory exercises and assignments completed during the Python programming course in my first year of the Bachelor's Degree in Artificial Intelligence.

The repository serves as a practical record of my foundational programming skills, algorithmic thinking, and hands-on experience with Python and its data science ecosystem.

## 📂 Repository Structure

The project is organized into two main sections, tracking the progression of the course:

* **`lab1/` (First Part):**
    * Contains introductory exercises covering Python basic syntax, variables, conditions, and loops.
    * Implementation of fundamental data structures (lists, tuples, dictionaries, sets).
    * Core problem-solving tasks from the initial lecture series.

* **`lab2/` (Second Part):**
    * Advanced exercises focusing on functions, file handling, and exception management.
    * Introduction to data manipulation, scientific computing, and data visualization.
    * Core libraries utilized: **NumPy**, **Pandas**, **SciPy**, **Matplotlib**, and **Seaborn**.

## 🚀 Getting Started

### Prerequisites
To run the scripts in this repository, you need to have Python installed on your system along with the required data science libraries. You can install them via pip:

```bash
pip install numpy pandas scipy matplotlib seaborn


### Installation & Execution
1. Clone the repository to your local machine:
   ```bash
   git clone [https://github.com/samueleantonutti/programminglab.git](https://github.com/samueleantonutti/programminglab.git)

2. Navigate into the specific lab folder:
   ```bash
   cd programminglab/lab2

3. Run any specific exercise script:
   ```bash
   python exercise_name.py
